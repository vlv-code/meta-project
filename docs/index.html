Architecture

Core Capabilities

Git-native Memory

Transparent Markdown knowledge base (architecture.md, boundaries.md, observations.md, tasks.md, weak_spots.md) with deterministic compaction.

Dynamic Role Synthesis

manage-meta-project analyzes the repo and composes hybrid agent roles (profile.md, system_prompt.md, notes.md) instead of forcing fixed templates.

Machine-Enforced Boundaries

Green, Yellow, and Red zones with Default Deny — validated locally via hooks and in CI via check_boundaries.py.

Thin Cross-Harness Hooks

Zero-dependency dispatcher (hooks/dispatch.py) and installer (hooks/install.py) across 6 harnesses; silent no-op outside Meta-Project repos.

Deterministic Updates & Inspection

Zero-write repo classifier (inspect_meta_project.py), SHA-pinned atomic updates (update_meta_project.py), and clean decommissioning.

Evidence-First Triage

triage-incident separates hypotheses from verified facts until backed by concrete artifacts.

Distribution

Install

Native manifests for Claude Code, Cursor, Codex, GitHub Copilot, and Gemini CLI in one repository. 

/plugin marketplace add vlv-code/meta-project
/plugin install meta-project

Per-skill installers copy only skill folders. sync-architecture is standalone; the other 9 depend on scripts/ and templates/ — install the full plugin when possible.

Boundaries

Zone Policy & Path Check

Every repository path maps to an explicit zone in boundaries.md. Anything unmapped stops execution.

GREEN

Docs, tests, standalone utilities — autonomous edits allowed.

YELLOW

Skills, templates, core logic — edits require verification.

RED

Passports, secrets, migrations, CI policy — explicit confirmation required.

DEFAULT DENY

Unmapped paths halt execution — no silent improvisation.

check_boundaries.py >
GREEN · Autonomous edits allowed
