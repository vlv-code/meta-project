Why

Prompt files tell the agent what to do. Meta-Project enforces it: a boundary gate in CI, thin hooks in six harnesses, and evidence-first triage.

Промпт-файлы говорят агенту, что делать. Meta-Project это принуждает: гейт границ в CI, тонкие хуки в шести харнессах и triage по уликам.

🫣 Boundary Gate

Green / Yellow / Red zones with Default Deny: unmapped paths halt the agent. Enforced in CI against a trusted-base revision and locally via thin hooks.

🪕 Thin harness hooks

Zero-dependency adapters for Claude Code, ZCode, Cursor, Gemini CLI, GitHub Copilot and Codex: session context, PreToolUse decisions, failure capture.

🧭 10 skills

Init, manage, decommission, ground, scan, tune, update, record-observation, sync-architecture, triage-incident — each with explicit ownership boundaries.

🔍 Deterministic inspection

Zero-write inspector classifies a repo into canonical states and prints a facts digest so unchanged slices need no re-read.

📦 Managed updates

SHA-pinned updates with an atomic journal, offline cache fallback and a lock file — local edits preserved via local_repo_data markers.

🔬 Evidence-first triage

Probe, record evidence, promote: hypotheses stay hypotheses until an artifact proves them.

Install

Three channels, one framework. Works with Claude Code, ZCode, Cursor, Windsurf, Gemini CLI, GitHub Copilot and Codex.

Три канала, один фреймворк. Работает с Claude Code, ZCode, Cursor, Windsurf, Gemini CLI, GitHub Copilot и Codex.

Claude Code plugin

Full framework as a single plugin.

/plugin marketplace add vlv-code/meta-project
/plugin install meta-project

For VS Code, Cursor, Copilot, Codex.

npx plugins add vlv-code/meta-project

skills.sh (per-skill)

Pick individual skills.

npx skills add vlv-code/meta-project

⚠ Per-skill installers copy the skill folders only. sync-architecture is the only fully standalone skill; the other nine need the repository's scripts/ and templates/ — prefer the full plugin or package.

⚠ Установщики отдельных навыков копируют только папки навыков. sync-architecture — единственный полностью автономный навык; остальные девять требуют scripts/ и templates/ репозитория — предпочтите полный плагин или пакет.

Hook matrix

Тонкие адаптеры (без дублирования движков политик) для шести харнессов — один JSON-объект на событие, молчаливый no-op вне репозитория Meta-Project, fail-closed там, где поддерживается.

Zones

Every path in the repo maps to a zone. The agent reads the map; the gate enforces it.

Каждый путь в репо отображён в зону. Агент читает карту; гейт принуждает.

GREEN

Docs, tests, standalone utilities — the agent modifies autonomously.

YELLOW

Skills, templates, core logic — modifications with mandatory verification.

RED

Passport, secrets, migrations, CI policy — explicit user confirmation required.

DEFAULT DENY

Anything unmapped halts the agent. No silent improvisation.
