Architecture

Built for real repositories, enforced in code

Prompt files only ask an agent to follow instructions. Meta-Project backs every convention with deterministic Python validators, CI boundary gates, and thin multi-harness hooks.

Boundary Gate (Default Deny)

Green / Yellow / Red zones enforced in CI against a trusted-base revision and locally via thin hooks. Unmapped paths halt the agent immediately.

Git-Native Project Memory

Transparent Markdown knowledge base (architecture.md, boundaries.md, observations.md, tasks.md, weak_spots.md) with automated compaction (compact_memory.py). Fully auditable via git diff, no hidden local DB.

Dynamic Role Synthesis

manage-meta-project inspects the repo and builds vendor-neutral agent roles (profile.md, system_prompt.md, notes.md)—merging or extending competencies to fit actual team count and sharing state live across parallel harnesses.

Thin Cross-Harness Hooks

Single hooks/dispatch.py router for 6 harnesses (Claude Code, ZCode, Cursor, Gemini CLI, GitHub Copilot, Codex). One JSON object per event, silent no-op outside a Meta-Project repo, fail-closed where supported.

Deterministic Inspection & Managed Updates

Zero-write classifier (inspect_meta_project.py) outputting canonical state digests so unchanged slices need no re-read, plus SHA-pinned atomic updates (update_meta_project.py) with journal, lock file, offline cache fallback, and local_repo_data markers.

Evidence-First Triage

Structured investigation via triage_incident.py: probe, record verifiable artifacts, promote confirmed findings. Hypotheses stay hypotheses until proven.

Boundary Model

Zone Policy Explorer

Every path in the repository is mapped to an explicit zone in boundaries.md. Select a zone or test any file path below to inspect how the gate responds before a write lands.

GREEN

Autonomous Modification Zone

Low-blast-radius paths such as documentation, test suites, and standalone utilities. The agent may edit freely without stopping for extra approval.

Distribution

          
Install Meta-Project

          

            Four native installation channels backed by five plugin manifests in one repository. Works across Claude Code, ZCode, Cursor, Gemini CLI, GitHub Copilot, VS Code, and Codex.
          

        


        

          

            
            
            
            
          


          

            

              Full framework with skills, Python validators, templates, and native hook definitions.
            


            

              
/plugin marketplace add vlv-code/meta-project
/plugin install meta-project

              
            

          

        


        
        

          

            Optional: Wire lifecycle hooks across harnesses
            
              For multi-harness setups (Cursor, Gemini CLI, Copilot, Codex, Claude Code), run the stdlib hook installer to register thin adapters pointing to hooks/dispatch.py.
            
          

          

            python3 hooks/install.py
            
          

        


        
        

          
          
            Per-skill installers copy skill folders only. sync-architecture is the only fully standalone skill; the other nine require scripts/ and templates/ — prefer installing the full plugin or extension.
